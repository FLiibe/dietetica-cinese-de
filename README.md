# Chinesische Diätetik — Acu Salud Akademie

German landing page and Hotmart sales funnel.

## Hosting

Static site, no build command or dependencies required. Publish directory: `dist`.

Routes: `/`, `/upsell`, `/downsell`, `/upsell-2`, `/downsell-2`, `/danke`.

The offer button links to the German Hotmart checkout. The four upsell/downsell pages include the Hotmart Sales Funnel Widget. Pixel and UTM scripts are installed on the main landing page.

## Local preview

Run `python3 -m http.server 8000 --directory dist`, then open http://localhost:8000.
